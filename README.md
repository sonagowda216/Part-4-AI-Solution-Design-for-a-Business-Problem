# Part 4: AI Solution Design for a Business Problem

## Overview
Design an AI-based solution for Insurance Claim Fraud Detection. Covers problem definition, data requirements, model selection, evaluation metrics, and responsible AI.

## Folder Structure
```
part-4-ai-solution-design/
├── README.md
├── notebook.ipynb
├── requirements.txt
├── solution_report.md
└── diagrams/
    └── solution_architecture.png
```

## Tasks
1. Choose a Business Domain (Insurance)
2. Define the Business Problem (Fraud Detection)
3. Identify AI Task Type (Binary Classification)
4. Data Requirement Plan
5. Model Recommendation (XGBoost / Feed-Forward NN)
6. Evaluation Plan (Recall, F1, AUC-ROC, Business KPIs)
7. Responsible AI Considerations
8. Final One-Page Solution Summary

## How to Run
```
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```
